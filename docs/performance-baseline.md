# خط الأساس لأداء النظام (Performance Baseline)

تم قياس خط الأساس لنقاط النهاية الحية على بيئة Render الحية (`https://mikrotik-api-yn0e.onrender.com/api/v1`) وقاعدة بيانات Supabase PostgreSQL.

- **تاريخ وساعة القياس:** 10 أكتوبر 2026 (03:50 UTC / 06:50 بتوقيت الخرطوم/صنعاء)
- **أداة القياس:** سكربت Node.js مستقل ينفذ طلبات HTTPS متتالية مع حساب زمن الذهاب والعودة الدقيق بواسطة `process.hrtime.bigint()`.
- **عدد العينات لكل نقطة:** 5 عينات فعلية (N = 5).
- **حساب المؤشرات:** Min، الوسيط P50، الـ P95، Max، والمتوسط الحسابي (Average).

## ملاحظات خط الأساس والتحليل الأولي:
1. **أسرع نقطة:** فحص الصحة `/health` بمتوسط 382.5 ms ووسيط 355.1 ms، وهي تمثل الحد الأدنى لزمن اتصال الشبكة الدولي ذهاباً وإياباً (Round-trip ping + SSL handshake).
2. **تسجيل الدخول (`/auth/login`):** وسيط 2525.6 ms ومتوسط 2599.9 ms ناتج عن المعالجة الحسابية المشددة لخوارزمية التجزئة `Argon2id` (معاملات الأمان: `memoryCost: 65536, timeCost: 3, parallelism: 4`) على معالجات بيئة Render المشتركة المحدودة الموارد.
3. **لوحة التحليلات (`/analytics/dashboard`):** وسيط 2793.5 ms ومتوسط 2980.6 ms (تحسنت مقارنة بالقياس السابق 4274 ms، لكنها ما زالت الأثقل بسبب تعدد استعلامات التجميع المتزامنة).
4. **جلب الكروت (`/cards?limit=50`):** حجم الاستجابة 32.1 kB وتستغرق P50 = 2240.2 ms لنقل وتجهيز مصفوفة الكروت.
